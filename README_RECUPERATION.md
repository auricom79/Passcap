# Pass Cap — sources récupérées

Cette archive contient les fichiers publics actuellement servis par `https://passcap.org/`, récupérés le 23 novembre 2026.

## Contenu

- `index.html` : page principale
- `confidentialite.html` : politique de confidentialité
- `styles.css` : styles du site
- `app.js` : logique de l’interface
- `data.json` : catalogue général
- `map-data.json` : géométrie de la carte
- `data/departments/` : 101 fichiers départementaux
- `favicon.svg`, police et licence des icônes

## Limites

Il s’agit d’une récupération exacte des fichiers publics déployés. L’historique Git, les anciennes versions, les fichiers de travail non publiés et les éventuels secrets ne peuvent pas être reconstruits depuis le site public seul.
