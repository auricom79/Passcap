# Passcap

Sources récupérées du site public [passcap.org](https://passcap.org) le 23 novembre 2026.

Le dépôt sert de sauvegarde durable et de nouvelle base de travail pour :

- conserver le site et son historique ;
- améliorer le référencement avec des pages par département, ville et besoin d’accessibilité ;
- actualiser les événements provenant des sources publiques ;
- préparer les futures publications de `passcap.org`.

## État de la récupération

Le frontend public, les modules JavaScript, les styles, les ressources et les données départementales ont été récupérés. Le code serveur privé, l’historique antérieur et les secrets ne sont pas exposés par le site public et ne figurent donc pas dans cette première sauvegarde.

## Source publique de référence

La version actuellement en ligne sur `passcap.org` reste la référence fonctionnelle tant que le code serveur communautaire n’a pas été rattaché à ce dépôt.
